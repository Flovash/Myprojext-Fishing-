Fish Game Table: Start Here

Updated 2026-10-18 by Claude Code. This is the readable guide to the whole project, for you and for your chat Claude. The working files (.json, .csv, .md) stay in the folder for Claude Code; everything important is summarized here and in the Fish & Routes Google Sheet next to this doc.

1. What this project is

Peacock Reef: a custom 10-seat fish table game (points only, friends in a garage). Two weapons: the gun (shared odds) and the fishing pole (personal, strategic). Target payback about 97-98% over a week.

Law zero: movement never changes catch chances or pays. Routes, formations, seasons and plays decide where and when fish swim, never the odds. Catch chance per hit = group payback / average multiplier.

2. For your chat Claude: designing new fish and routes

  1. Look at the Fish & Routes sheet to see every fish and route that exists (with lab results).
  2. Write one new fish as a JSON file named after the fish (for example lanternfish.json) and save it in the folder new_fish_inbox (Drive folder id 129nhGGTTBJJ3AiuYubKiEd1k0es32gnI). A Google Doc in that folder containing the same JSON also works. To add routes to an existing fish, write the same format with the fish's existing id.
  3. Tell the owner it is there. Claude Code imports it (node route_library/tools/import_fish.js new_fish_inbox/lanternfish.json), which checks it, lists anything to fix, draws a sketch of every route, and updates the sheet.

The screen

  • Points are [x, y] fractions of the screen. x: 0 = left edge, 1 = right edge. y: 0 = top seat row, 1 = bottom seat row. There are 5 seats along the top and 5 along the bottom, at x = 0.1, 0.3, 0.5, 0.7, 0.9.
  • Start and end every route off screen (for example -0.1 or 1.1) so the fish swims in and out.
  • The game draws a smooth curve through the points; add "sharp": true for straight lines with hard corners.
  • Every route is automatically mirrored left-right and top-bottom and run backwards, so one drawing gives 8 lanes.

Fields

  • group: tiny, small, medium, big, boss or special. The group sets the odds (tiny/small 98%, medium 97%, big 95%, boss 90%, special 95%); designs never set odds.
  • group_sizes: [smallest school, largest school].
  • dur: [min, max] seconds on screen. Typical: tiny/small 8-12, medium 12-25, big 20-35.
  • Optional per route: pauses (stop at a fraction of the route for a few seconds: the "now!" moment), sharp, crosser (fast fish crossing the whole screen; at most 2 at once), edge (seat edges only), shifts (also slide the route left/right), lanes (also run it at other heights).
  • Not designed yet, so open for new routes: small fish (Clownfish, Butterflyfish, Puffer, Lionfish, Seahorse, Minnow, Anchovy), specials (Bomb Crab, Lightning Eel) and bosses (Megalodon, Kraken, Giant Squid, Healer Jellyfish).

3. The director: what is built (2026-10-18)

From the four plans in the folder (PLAN_director_tracking, brain, memory, theories), the tracking plan is built; brain, memory and theories come next, in that order. The game is now version 8.

  • Every fish and route has its own folder in route_library (route, rules, tracked stats, sketch).
  • The medium fish swim the designed routes, with the lane rules (at most 2 fast crossers, counterflow against the Shark, lane reservation around big fish, nothing crosses the middle during a Shark split).
  • Every school the director sends is logged: who it passed, hits, catches, escapes, first catch. The lab keeps a scoreboard for every fish + route + formation + size.
  • Tuna schools of 2-6 in four formations: arc, echelon, line, ball.
  • Seasons (Winter, Monsoon, Summer reef) change which routes and formations are favored and tint the water.
  • Five plays ("if this, then send that"), each switchable.

What it means:

  • Everything runs: no errors in 21 nights, and the bookkeeping check (lab totals vs the game's own ledger) passed every time. Hits per catch match the designed odds for every medium fish (Tuna about 11, Turtle about 33), so law zero holds.
  • The new routes, formations, seasons and plays did not change session length or dry spells for the bots. That is expected: bot players do not get bored, excited or tired, so they cannot react to variety or timing. These settings need real players (or smarter bot types) to judge. Season length can stay at 6 for now.
  • Payback differences between columns (88-97%) are night-to-night luck, mostly bosses: each column's 3 nights spread over 4-8 points. Payback runs under the 97-98% target in every column, the old game too, so that is a separate thing to look at (big fish and bosses pay back well under their design over a night).
  • The plays fire about 210 times a night. "Cold table" plays almost never fire because 10 bots keep the table busy.
